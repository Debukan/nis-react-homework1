# Мини-маркет

UI-кит и каталог на styled-components: светлая и тёмная тема, поиск, фильтр категорий и добавление в корзину.

## Запуск

```bash
cd homework1
npm install
npm run dev
```

Сборка: `npm run build`. Тема запоминается в `localStorage`, а если выбора ещё не было - берётся `prefers-color-scheme`.

## styled-components против CSS Modules

Когда собирал кнопку «В корзину», вариант, размер и loading проще было отдать пропсами. В CSS Modules под это ушли бы классы и clsx, здесь хватает `$variant` и `$size`. С темой вышло так же: light и dark одного типа, `ThemeProvider` подменяет объект, и тёмную схему отдельно копировать не пришлось. Опечатки TypeScript ловит сразу, а CSS Modules - нет: Vite типизирует классы как строки, опечатка просто ничего не красит. Спиннер я написал через `keyframes` в файле кнопки, он не живёт отдельным css, который потом страшно выкидывать. Стили при этом считаются в браузере на рендере, у модулей css уже собран, и с серверными компонентами им легче. Карточки почти не зависят от пропсов, их я бы сделал модулями, а кнопку оставил на styled-components.
